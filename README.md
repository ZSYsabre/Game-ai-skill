# 游戏分析写作

一个面向 ChatGPT/Codex 的中文游戏分析写作 Skill。

它用于游戏评测、玩法与叙事拆解、开发复盘、AI 辅助开发分析、独立游戏观察和行业评论，强调以事实材料支撑判断，并将现实事实、开发者自述、玩家反馈和作者推断分开。

## 文件结构

- `SKILL.md`：主工作流与写作规范
- `references/analysis-framework.md`：游戏分析角度与文章组织方法
- `references/ai-development.md`：AI 游戏开发案例分析方法
- `agents/openai.yaml`：Skill 展示与调用配置
- `assets/icon.svg`：Skill 图标

## 使用方式

将仓库内容作为 Skill 目录安装，并通过“游戏分析写作”调用。

## 适用场景

- 游戏评测与深度解析
- 玩法、叙事、难度和界面分析
- 独立游戏及开发过程复盘
- AI 辅助游戏开发分析
- 游戏行业与商业表现观察
- 公众号文章和视频口播稿
