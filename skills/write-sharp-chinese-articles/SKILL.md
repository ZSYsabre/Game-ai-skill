# 锋利中文写作

把一篇文章写成读者愿意转发、反驳和讨论的观点作品。争议来自真实矛盾和明确判断，深刻来自对结构变化的解释，不靠夸张或喊口号。

## 写作原则

1. 先有判断，再找材料。全文必须能压缩成一句合理的人可以反对的主张。
2. 争议必须有对象。指出哪种共识、规则、利益或审美正在被挑战，不泛泛谈变化。
3. 攻击观点和机制，不攻击普通人，不编造动机，不靠羞辱制造热度。
4. 把最强反方意见写出来并正面回答。不要挑软柿子。
5. 结尾必须增加一层新认识，不能换词复述正文。

## 工作流程

### 1. 找到真正的矛盾

先从材料中选一个核心冲突，优先使用以下类型。

- 新工具与旧规则
- 主流标准与边缘表达
- 效率与人的价值
- 商业正确与真实需求
- 技术进步与审美贬值
- 个体选择与行业结构

如果材料只能支持温和结论，不强行制造极端立场。继续研究，或把争议缩小到证据能够承担的范围。

### 2. 写出可争论的中心句

中心句要满足四个条件。

- 有明确主语
- 有方向判断
- 能找到反对者
- 能被正文材料证明或推导

弱判断示例为“AI正在改变电影”。

强判断示例为“AI越擅长制造电影感，拒绝精致的画面越可能成为新的作者语言”。

### 3. 设计话题入口

标题和开头优先制造认知冲突，不使用与正文无关的夸张。

可选入口包括反常识判断、具体失败、意外数据、公开冲突、历史类比和一句带刺的问题。

开头在三到五段内完成三件事。

1. 给出一个能被看见的场景或事实。
2. 明确常规判断。
3. 推翻或质疑这个判断，交出全文主张。

不要用“随着……的发展”“在这个时代”“今天我们来聊聊”起笔。

### 4. 用材料推进冲突

每一部分只承担一个论证任务。常用顺序如下。

1. 事件为何引发注意
2. 主流解释是什么
3. 主流解释遗漏了什么
4. 历史、产品或行业材料如何改写理解
5. 最强反方意见是什么
6. 作者最终站在哪一边

现实题材要核验人物、时间、数据、技术能力和引语。时效性事实优先查找官方资料、当事人陈述和可靠媒体。找不到来源就降低确定性或删掉，不补写看似合理的细节。

### 5. 写出有代价的立场

立场要说明支持什么，也要承认它的代价。允许使用“我认为”“我不接受”“我更愿意相信”等第一人称表达。

不要把每个问题都写成双方各有道理。材料明显偏向一方时直接判断，同时准确呈现反方最强理由。

### 6. 完成深刻结尾

结尾按三层推进。

1. 回到开头的个案，给它重新命名。
2. 提炼个案背后的行业规则、权力关系、审美标准或人性处境。
3. 推演下一步变化，说明谁将获得机会，谁会失去优势，创作者需要证明什么。

最后一句应当脱离原案例仍然成立，同时保留文章独有的意象。优先写判断句，少写号召句。

不使用以下空结尾。

- 未来可期
- 让我们拭目以待
- 这值得每个人深思
- 只有百花齐放，行业才有希望
- 时代终将奖励坚持的人

## 平台适配

### 公众号

开头更快，段落更短。每二到四段出现一次可单独截图的判断句。标题可以更锋利，正文必须兑现标题。

### 人人都是产品经理

把争议落到产品机制、商业利益、用户行为和行业角色。除观点外给出方法、因果链或可操作启示。

### 少数派

减少营销腔和宏大叙事。增加个人观察、工具细节、实践过程和使用边界，让判断从真实体验中长出来。

## 去AI味

- 长短句交替，允许短句单独成段。
- 使用具体名词、动作、数字和场景，删除抽象套话。
- 少用“此外”“然而”“值得注意的是”“总而言之”。
- 每篇最多出现一次“不是……而是……”式翻案。
- 不连续使用三组排比，不把每一节都写成相同结构。
- 不假装绝对客观。需要判断时用自然的第一人称承担观点。
- 保留适度情绪和个人品味，但每个尖锐判断都要有理由。

## 交稿前检查

逐项确认。

- 标题是否包含真实冲突
- 前五段是否已经交出主张
- 是否存在一句可被合理反驳的中心判断
- 是否至少有两个具体材料支撑主张
- 是否回答了最强反方意见
- 是否出现无来源的数据或引语
- 是否有一段只在重复上一段
- 结尾是否比正文多推进了一层
- 最后一句是否来自本文，而不是万能金句

任何一项不满足就继续修改，不用空洞金句遮盖论证缺口。
